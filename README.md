# Skolkalender Esbo

Prenumerationskalendrar (.ics) med lov och arbetstider för Finno skola och Mattlidens skola (svenskspråkiga grundskolor i Esbo), läsåren 2026–2027 och 2027–2028.

| Kalender | Adress |
|---|---|
| Båda skolorna | https://hemosk.github.io/skolkalender-esbo/skolkalender.ics |
| Finno skola | https://hemosk.github.io/skolkalender-esbo/finno.ics |
| Mattlidens skola | https://hemosk.github.io/skolkalender-esbo/mattliden.ics |

Outlook på webben: Kalender → Lägg till kalender → Prenumerera från webben.

## Uppdatera

Datum och källor finns i `kalender.js`. Ändra där och kör `node build.js`, committa och pusha.

## Källor

- Nämnden Svenska rum 30.10.2025 § 104: https://espoo-sv.oncloudos.com/kokous/20251516-6.PDF
- Esbo stad, arbets- och lovtider: https://www.espoo.fi/sv/fostran-och-utbildning/arbets-och-lovtider
- Skolornas sidor på espoo.fi (skolvisa avvikelser)
- Helgdagar (påsk, självständighetsdagen, första maj, Kristi himmelsfärd 2028) är beräknade allmänna helgdagar.
